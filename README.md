# Deskripsi tugas
Tugas merupakan latihan mandiri Pemograman Web menggunakan JavaScript dengan mengintegritaskan Array dan Function.
Terdapat dua program yang dibuat, yaitu:
1. Sistem pengelolaan inventaris laboratorium komputer
   
   Program ini digunakan untuk mengelola data barang yang tersedia di laboratorium komputer. Program dapat menampilkan daftar
   barang, menambahkan barang baru, mencari barang, dan mengahpus barang dari daftar inventaris.
   
Function yang digunakan:

tampilkanBarang() : Menampilkan seluruh daftar barang.

tambahBarang() : Menambahkan barang baru ke dalam Array.

cariBarang() : Mencari posisi atau indeks barang.

hapusBarang() : Menghapus barang dari daftar inventaris.

2. Pengolahan Nilai Praktik Siswa

Program ini digunakan untuk mengolah nilai praktik siswa. Program dapat menampilkan seluruh nilai, menghitung rata-rata, menghitung jumlah siswa yang tuntas, dan menghitung jumlah siswa yang belum tuntas.

Batas ketuntasan yang digunakan adalah 75.

Function yang digunakan:

tampilkanNilai() : Menampilkan seluruh nilai siswa.

hitungRataRata() : Menghitung rata-rata nilai siswa.

hitungJumlahTuntas() : Menghitung jumlah siswa yang memenuhi batas ketuntasan.

Cara Menjalankan Program

Buka folder tugas menggunakan Visual Studio Code.

Pastikan Node.js sudah terpasang.

Buka Terminal di Visual Studio Code.

Jalankan program pertama dengan perintah:

node 01-inventaris-lab.js

Jalankan program kedua dengan perintah:

node 02-pengolahan-nilai.js

Tekan Enter untuk melihat hasil program.
